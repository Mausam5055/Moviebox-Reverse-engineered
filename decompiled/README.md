## Decompilation Methodology

1. **Java Source Reconstruction (JADX v1.5.6):**
   - Executed using OpenJDK 25 LTS with `--show-bad-code` enabled to preserve method logic even when control flow structuring encountered complex try-catch constructs.
   - Decompiled 62,001 classes into 32,549 structured Java source files under `java_source/sources/`.

2. **Bytecode Preservation (Apktool v3.0.3):**
   - Disassembled all 7 DEX files into exact Dalvik Smali representations (`smali/` through `smali_classes7/`) ensuring zero loss of opcode fidelity.
   - Decoded Android binary XML resources (`resources.arsc` and `res/`) into editable XML files.

3. **Binary Artifact Preservation:**
   - Raw DEX binaries (`classes.dex` .. `classes7.dex`) are preserved unaltered in `raw_dex/`.
   - Native C/C++ shared libraries (`.so`) are preserved across both `arm64-v8a` and `armeabi-v7a` architectures in `native_libraries/`.
   - The original unmodified APK is preserved under `original/original.apk`.
